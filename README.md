
# OLA Ride Booking Analysis

A data analytics portfolio project exploring ride-booking performance using **MySQL, SQL, and Power BI**.

## Project Overview

This project analyses a synthetic OLA-style ride-booking dataset to explore booking outcomes, cancellation patterns, vehicle performance, and ride trends over time.

## Tools Used

- **MySQL** — data querying and analysis
- **SQL** — filtering, aggregation, grouping, and business analysis
- **Power BI** — dashboard development and visualisation

## Business Questions

- What is the overall booking status breakdown?
- What are the main reasons for ride cancellations?
- How does booking volume change over time?
- How does performance vary by vehicle type?
- What insights can help improve the booking experience?
